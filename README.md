# Mando

Control administrativo de varios negocios en una sola PWA: nómina, inventarios, requisiciones y reportes.

Se construye por specs: cada funcionalidad pasa por entrevista → `spec.md` aprobada → `plan.md` → `tasks.md` →
código con tests → validación RF por RF. Empieza por:

- `AGENTS.md`: proceso, comandos y reglas de trabajo.
- `docs/constitution.md`: principios que no se negocian.
- `docs/roadmap.md`: orden de las specs.
- `docs/architecture.md`: stack, capas y lecciones aprendidas.
- `specs/`: una carpeta por spec.
